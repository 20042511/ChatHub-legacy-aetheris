# ChatHub

**Simple Multi-Provider AI Chat for Android**

ChatHub is a clean, fast Android chat client supporting OpenAI, Anthropic, Groq, OpenRouter, and any OpenAI-compatible endpoint.

## Features

✅ Multiple AI providers in one app  
✅ Streaming responses  
✅ Encrypted API key storage  
✅ Material 3 design  
✅ Markdown rendering  
✅ Local conversation history  

## Tech Stack

- **Language:** Kotlin 2.1  
- **UI:** Jetpack Compose + Material3  
- **Architecture:** MVVM + Hilt  
- **Database:** Room  
- **Network:** OkHttp  

## Requirements

- Android 8.0+ (API 26+)  
- Your own API keys  

## Build

```bash
git clone https://github.com/20042511/ChatHub.git
cd ChatHub
./gradlew assembleDebug
```
